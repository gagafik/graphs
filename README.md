# 📊 Дашборд успеваемости школы

Интерактивный дашборд на [Streamlit](https://streamlit.io/) для анализа оценок:
рейтинги предметов, тепловая карта «класс × предмет», профили учеников,
поиск выбросов (некорректных оценок), фильтры по классам / параллелям /
предметам / датам и экспорт в CSV/Excel.

## Запуск

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Приложение откроется в браузере по адресу http://localhost:8501.

## Данные

При старте приложение ищет Excel-файл с данными в следующем порядке:

```
Marks 2526.xlsx
marks_2526.xlsx
data/Marks 2526.xlsx
data/marks_2526.xlsx
```

Данные читаются с листа **`Average year, no teacher`**. Если файл не найден,
показываются демо-данные.

Также файл можно загрузить прямо в интерфейсе (сайдбар → «📁 Загрузка данных»).
При загрузке используется тот же именованный лист, а если его нет — первый лист книги.

### Требуемые столбцы

| Столбец   | Описание                          |
|-----------|-----------------------------------|
| `Student` | Имя ученика                       |
| `Class`   | Класс (например, `10A`)           |
| `Subject` | Предмет                           |
| `Average` | Средний балл (число, 0–100)       |
| `Date`    | *(опционально)* дата контрольной точки |

Строки с пустым/нечисловым `Average` отбрасываются автоматически.

## Вкладка «⚠️ Выбросы»

Оценки вне диапазона `0–100` считаются ошибочно выставленными. Вкладка показывает
их по полным данным (независимо от слайдера диапазона) со сводкой по связке
«класс + предмет» — так быстро видно, где именно балл ввели некорректно.
Список можно выгрузить в CSV.

## Пресеты фильтров

Сохранённые наборы фильтров хранятся локально в `filter_presets.json`
(этот файл в `.gitignore` — он специфичен для каждой установки).
Пресеты можно экспортировать и импортировать через JSON в сайдбаре.
